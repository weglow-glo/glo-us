# glo 리뷰 운영 정책

> 최종 수정: 2026-07-22 · 구현: `web/src/app/api/reviews/*`, `web/src/app/admin/reviews/*`, 마이그레이션 `0008_customer_reviews.sql`

## 1. 작성 자격

- **배송완료된 주문을 보유한 로그인 회원**만 작성할 수 있다.
- **주문 × 상품(SKU)당 1회.** 한 주문에 여러 상품이 담기게 되면(향후 SKU 확장) 상품별로 각각 작성할 수 있다. 현재는 GL-01 단일 SKU.
- 작성 기한: **배송완료 후 90일 이내.**
- 재구매 시 새 주문에 대해 다시 작성할 수 있다.

## 2. 형식

| 항목 | 기준 |
|---|---|
| 별점 | 1~5 (필수) |
| 텍스트 | 20자 이상 ~ 2,000자 (필수) |
| 사진 | 최대 **5장**, 장당 **10MB** (jpg·png·webp·heic) |
| 영상 | 최대 **1개**, **50MB** (mp4·webm·mov — 1080p 기준 약 1분) |

- 파일은 브라우저에서 스토리지로 **직접 업로드**한다 (서버 경유 시 Vercel 4.5MB 제한).
- 스토리지 버킷(`review-media`) 자체에 50MB·형식 제한이 걸려 있어 우회 업로드도 차단된다.

## 3. 게시·검수

- **텍스트 리뷰: 검수 없이 즉시 게시.** 포인트도 즉시 지급.
- **사진·영상 포함 리뷰: 리뷰(텍스트)는 즉시 게시**하되, 미디어는 **블러 처리 + "검수 중" 표시**로 노출한다.
  - 관리자 승인 → 블러 해제, 미디어 정상 노출 + 추가 포인트 지급.
  - 관리자 반려 → 미디어만 숨김(텍스트 리뷰는 유지), 추가 포인트 미지급.
- 관리자 검수 기준:
  - **효능·질병 표현**(미백·주름·기미 개선, 치료·완화 등)이 미디어에 드러나면 반려 — 고객 후기라도 판매 페이지 게시 시 광고로 간주된다(식품표시광고법).
  - 얼굴·개인정보가 과도하게 노출된 미디어는 반려.
  - **별점이 낮다는 이유로 숨기지 않는다** (전자상거래법상 구매후기 임의 삭제 금지).
  - 텍스트에 효능·질병 표현이 발견되면 관리자가 사후 숨김(hidden) 처리할 수 있다.

## 4. 포인트 (1P = 1원)

| 시점 | 지급 |
|---|---|
| 리뷰 제출 즉시 | **3,000P** (텍스트분) |
| 미디어 검수 승인 시 | **+2,000P** (사진/영상분) |

- 같은 리뷰에 같은 사유로 중복 지급되지 않는다 (DB unique 제약).
- 사용: 다음 구매 결제 시 차감. *(체크아웃 차감 기능은 후속 구축)*

## 5. 수정·삭제

- **본인 수정: 작성 후 48시간 이내**, 별점·텍스트만 수정 가능 (미디어 교체 불가).
- **본인 삭제: 불가.** 삭제는 관리자만 할 수 있다.
- 관리자 삭제·숨김 사유는 금지 표현·비방·개인정보 노출·도배 등으로 한정한다.
- 숨김 처리된 리뷰는 공개 목록·평점에서 제외되지만, **작성자 본인의 마이페이지에서는 계속 보이며** "게시가 중단되었습니다"로 안내된다. 숨김은 복구 가능, 삭제는 영구 제거.

## 6. 노출

- 상품 페이지 "고객 후기" 목록에 시딩 후기(체험단 유래)와 실구매 리뷰를 **구분 뱃지 없이 통합** 노출한다.
  - "구매 인증" 등의 표기는 실제 주문 연결 없이는 사용하지 않는다 (허위 표시 방지).
- 작성자 표기: 이름 첫 글자 + OO (예: 김 OO), 지역(시/도).
- 정렬: 별점순(기본)·최신순·도움순. 평점 평균에 모든 게시 리뷰가 반영된다.

## 7. 작성 유도 알림

- **배송완료 7일 후** 오전 10시(KST)에 문자(추후 알림톡) 1회 발송.
- 이미 리뷰를 작성한 주문·연락처 없는 주문은 제외. 주문당 1회만 발송(`review_requested_at`).

## 8. 법적 유의사항 (운영자 메모)

- 일반식품이므로 **기능성·질병 표현이 담긴 콘텐츠를 사이트에 게시하는 것 자체가 광고 위반**이 될 수 있다. 텍스트가 무검수인 만큼, 신고·모니터링으로 발견 시 즉시 숨김 처리할 것.
- 구매후기 임의 삭제·불리한 후기 숨김은 전자상거래법 위반 소지 — 삭제·숨김은 위 사유로만.
