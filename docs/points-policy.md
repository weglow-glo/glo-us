# glo 포인트 운영 정책

> 최종 수정: 2026-07-22 · 적립 규칙은 [review-policy.md](review-policy.md) §4 참조

## 1. 기본

- **1P = 1원.** 결제 시 상품 금액에서 차감한다.
- 적립: 리뷰 텍스트 3,000P / 미디어 검수 승인 +2,000P. (향후 이벤트 적립 확장 가능)

## 2. 사용

- **최소 사용·한도 제한 없음** — 1P부터 보유 잔액 전액까지 사용 가능.
- 결제(토스 승인) **성공 시점에 차감**된다. 승인 실패 시 차감되지 않는다.
- 잔액 검증·차감은 전부 서버에서 원자적으로 처리한다 (동시 결제 이중사용 방지).

## 3. 유효기간

- **지급일로부터 6개월.** 만료된 포인트는 잔액에서 자동 제외된다.
- 사용 시 **먼저 만료되는 적립분부터 차감**(FIFO)한다.
- **만료 30일 전** 문자로 1회 안내한다 (공정위 가이드라인).

## 4. 환불·취소 시 처리 (회수 정책)

| 상황 | 처리 |
|---|---|
| 포인트를 사용한 주문이 취소·환불됨 | 사용 포인트 **자동 복원** (새 적립 행, 복원일로부터 6개월). 카드결제분만 카드로 환불 |
| 리뷰를 작성한 주문이 환불됨 | 그 리뷰로 적립된 포인트를 **잔액 내에서 회수** ("리뷰 쓰고 환불" 어뷰징 방지). 잔액이 부족하면 부족분은 회수하지 않는다 (마이너스 없음) |
| 관리자가 리뷰를 삭제·숨김 | 포인트 **회수하지 않음** (성실 작성 고객 보호) |
| 부정 적립 적발 | 관리자 수동 조정(admin_adjust)으로 처리 |

- 포인트 사용분은 어떤 경우에도 **현금으로 환급되지 않는다** (포인트로만 복원).

## 5. 안내 문구 (고객 노출)

- 체크아웃: "보유 포인트 N P · 사용할 포인트 입력"
- 환불 안내: "포인트로 결제하신 금액은 포인트로 반환됩니다."
- 마이페이지: 잔액 + 이번 달 만료 예정 포인트 표시.
