— 07

접근성 가이드라인

모든 페이지에 적용된 a11y 패턴.

Skip link

키보드 사용자가 nav를 건너뛰고 메인 콘텐츠로 점프. 모든 페이지의 <body> 직후에 있음.

Focus visible

키보드 포커스 시 outline: 2px solid var(--accent). :focus-visible만 트리거 (마우스 클릭에선 안 나옴).

Reduced motion

@media (prefers-reduced-motion: reduce)에서 모든 애니메이션·트랜지션 0.01ms로 축소. 영상도 자동 hide.

aria-current="page"

현재 페이지의 nav 링크에 aria-current="page" 추가. 진한 색상으로 표시.

이 페이지는 내부용입니다.
robots: noindex,nofollow로 설정되어 검색엔진 노출 차단. URL 공유는 팀 내부로만.

토큰·컴포넌트 변경 절차:
1. 이 페이지 (_styleguide.html)에서 미리 시안 만들기 → 2. 디자인팀 리뷰 → 3. 개발자가 사이트 전체 페이지에 일괄 적용 → 4. 이 페이지도 동시에 업데이트

현재 한계:
각 HTML 페이지가 self-contained라 토큰을 한 곳에서 바꾸면 모든 파일에 동기화해야 함. Next.js 마이그레이션 (CLAUDE.md 참고) 후엔 tailwind.config.js 한 곳에서 관리.
